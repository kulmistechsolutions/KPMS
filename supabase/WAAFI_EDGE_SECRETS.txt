KPMS — WAAFI billing Edge Functions
====================================

Two credential sets (from WaafiPay merchant dashboard):

  API (direct EVC/ZAAD charge — what you have now):
    WAAFI_MERCHANT_UID=M0914298
    WAAFI_API_USER_ID=1008971
    WAAFI_API_KEY=API-xxxxxxxx

  HPP (redirect to hosted payment page — optional):
    WAAFI_MERCHANT_UID=M0914298
    WAAFI_STORE_ID=<store id>
    WAAFI_HPP_KEY=HPP-xxxxxxxx

Do NOT mix API_KEY with HPP_PURCHASE — that causes E10227 unauthorized.

Deploy:

  supabase functions deploy waafi-init-payment --project-ref gdfcqlfqgqcqgudjturq
  supabase functions deploy waafi-payment-webhook --project-ref gdfcqlfqgqcqgudjturq --no-verify-jwt
  supabase functions deploy billing-daily-jobs --project-ref gdfcqlfqgqcqgudjturq --no-verify-jwt

Secrets (never commit values):

  supabase secrets set WAAFI_MERCHANT_UID=... WAAFI_API_USER_ID=... WAAFI_API_KEY=... WAAFI_ASM_URL=https://api.waafipay.com/asm KPMS_APP_URL=http://localhost:PORT --project-ref gdfcqlfqgqcqgudjturq
